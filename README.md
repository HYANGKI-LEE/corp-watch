# corp-watch

개별 기업의 최근 실적과 주요 재무 지표를 보는 대시보드예요.

## 데이터 갱신 순서

1. DataGuide에서 `(★)DataGuide.xlsx`를 Refresh한 뒤 `data/` 폴더에 넣어요. 원본 엑셀은 `.gitignore`에 등록돼 있어서 커밋되지 않아요.
2. 지표를 계산해요.
   ```
   python scripts/build_metrics.py
   ```
   결과는 `output/metrics.json`(대시보드용)과 `output/metrics_long.csv`(검증용)에 저장돼요.
3. (선택) 엑셀 Main 시트 값과 대조해요.
   ```
   python scripts/validate_main.py
   ```

## 구조

- `scripts/concepts.py`: DataGuide 항목을 표준 개념에 연결하는 매핑표와 지표 목록, 기준선이 들어 있어요.
  - 개념마다 후보 항목을 우선순위대로 적어두고, 기간별로 처음 값이 있는 후보를 써요.
  - 새 회사나 K-GAAP 회사가 들어와서 항목명이 다르면, 해당 개념의 후보 리스트 뒤에 추가하면 돼요.
- `scripts/build_metrics.py`: 회사마다 연결/별도 × 분기/연간 시리즈를 만들고 지표를 계산해요.
  - 손익·현금흐름은 분기 개별 값이고, 4분기 누적은 4개 분기 값을 더해서 만들어요.
  - 비율(잔액 기준)의 4분기 누적·3년 누적은 기간 평균 잔액으로 계산해요.
  - 최근 결산연도의 4개 분기 매출이 다 있으면 분기 주기를 기본으로, 아니면 연간 주기(비상장사 등)를 기본으로 써요.
  - 매출은 있는데 자산총계가 없는 분기는 잠정실적으로 표시해요.
